# DSH SSH

面向 DeepSeek Harness 的远端工作插件，将主机管理、浏览器终端、文件传输、代理和 AI 会话授权放在同一工作区。

[![npm](https://img.shields.io/npm/v/%40lemoncat7%2Fdsh-ssh)](https://www.npmjs.com/package/@lemoncat7/dsh-ssh)

## 功能

- SSH 主机与分组、固定目录、密码 / 私钥 / SSH Agent 认证，以及分组代理。
- 独立的「主机与项目」首页，支持卡片／列表、搜索、双击打开终端；AI 挂载单独操作。
- 跨主机统一多标签，每个标签内独立选择单屏、左右两屏、上下两屏或四格布局；离开工作台保留连接，返回或刷新恢复当前浏览器标签页内的终端与布局。SFTP 目录浏览，FTP / FTPS / SFTP 跨端点文件传输。
- 可配置连接超时与主机覆盖值；可选终端 SSH 连接复用（默认关闭），新标签共享认证但保持独立 shell。
- AI 只加载一个 `ssh` 工具，通过 `list / describe / call` 按需发现、查询和执行操作，减少常驻工具上下文。
- 文本、SQL、配置、图片、PDF 与静态 HTML 预览；无法安全预览或超限时提供下载。
- 按会话保留右栏标签、主机、目录、预览和滚动位置；打开面板定位当前挂载主机。
- 按会话授权的远端命令、AI 终端与文件工具，支持核验聊天授意后的临时 SSH 授权及指定看板任务授权。
- HTTP CONNECT、SOCKS5、SSH 跳板与端口转发，凭据库及加密 Gist 配置同步。
- 设置中导入、导出密码加密的配置备份，导入前预览数量并作为新副本添加。

## 安装

需要 Node.js **>=24.9.0**。不按 DSH 版本号限制安装或加载；兼容性测试作为历史记录保留，见[宿主兼容策略](docs/host-compatibility-policy.md)。

```bash
dsh plugin --profile web add @lemoncat7/dsh-ssh@latest
```

安装或升级后重启对应的 DSH Profile；`web` 请按实际使用的 Profile 调整。

打开「远端 → SSH 面板」添加主机，测试连接并确认主机指纹。浏览主机不会自动授予 AI 访问权限；为当前会话挂载主机或文件端点，再选择命令、终端和传输权限。

## 使用边界

凭据由 DSH 凭据服务保存，列表不返回明文；密钥库中已保存的密码可按需显示或复制，关闭后清除页面中的明文。SSH 与文件端点授权独立，文件下载到 DSH 会话目录不等于浏览器电脑。会话浏览状态仅在当前页面生命周期保留，不跨刷新。首次连接需确认指纹，公开端口监听默认拒绝。

## 宿主兼容策略

DSH 更新后不再为了补版本声明单独发布插件；按实际接口和功能验证、修复。[策略及历史测试入口](docs/host-compatibility-policy.md)。

### 工作台终端保留

离开工作台只停止页面订阅，返回时恢复当前会话的主机、标签、分屏及服务端保留的输出；刷新页面也可恢复。记录保存在当前浏览器标签页的 sessionStorage，不保存密码或终端正文。缩减布局时选择保留的终端，确认后关闭其余连接；关闭标签或关闭全部终端也会先确认；关闭失败会保留未成功关闭的窗格并提示错误。

终端有输出或页面订阅时保持连接。离开后连续 30 分钟没有输入、输出或订阅会回收，因此无输出的长任务仍建议使用 tmux/screen。服务重启、网络中断或回收后无法恢复原进程；页面提示重新连接，不自动重跑命令。服务端输出缓冲有上限，较早输出可能截断。
