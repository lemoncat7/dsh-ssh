# 会话工作台与文件浏览状态

- SSH 工作台使用宿主的会话内容区域，不再作为全局主面板覆盖当前会话选择。切换会话或打开其他插件时，工作台仍按原有约定关闭。
- 打开工作台时，优先选择当前会话已挂载的主机，并展开已挂载主机所属的分组。未挂载分组默认折叠；用户手动收起分组后，普通数据刷新不会强行展开。
- 右栏分别记录每个会话的标签页、所选主机，以及每个“会话＋主机”的浏览目录、打开文件和目录滚动位置。本地目录使用独立记录。关闭再打开、切换标签页或切换会话后恢复，但不跨浏览器刷新保存。
- 浏览状态只保留导航元信息，不缓存文件内容或权限，最多保留 128 个位置。恢复时重新请求目录和预览，继续经过服务端权限检查，不会自动修改会话工作目录。
- SQL、TXT、脚本、常见配置文件支持文本预览；未知后缀和无后缀文件也在大小限制内尝试识别。支持 UTF-8 与带 BOM 的 UTF-16；二进制、解码失败、读取不完整或预览失败时提供下载。UTF-16 文本不启用 UTF-8 Markdown 编辑。
- 文本预览上限为 1 MiB，图片/PDF 为 16 MiB；超过上限直接提供下载，不加载大文件正文。下载仍使用原有鉴权路径。

验证命令：`npm test`；隔离浏览器脚本 `scripts/verify-session-state.mjs` 使用本地 HTTP 测试数据，不访问真实主机。可通过 `SSH_PLAYWRIGHT_MODULE` 和 `SSH_REACT_DOM_MODULES` 指定现有 Playwright、React DOM 的位置。
