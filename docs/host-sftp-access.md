# 主机挂载与 SFTP 授权

- 当前会话挂载 SSH 主机后，自动获得该主机 SFTP 的浏览、远端互传及会话目录内上传/下载能力。SFTP 传输确认沿用主机的操作确认设置。
- 文件传输中的「FTP 会话访问」只列出独立 FTP/FTPS 连接，其浏览/传输权限和传输确认设置仅作用于 FTP/FTPS。混合传输分别检查两端权限，需要任一端确认时都会申请确认。
- SFTP 授权由服务端按有效挂载实时计算，不依赖客户端自动勾选。既有已挂载主机、服务重启后的会话、普通派生会话均适用；卸载或删除主机后，新调用不再获得对应权限。
- 旧版单独勾选但未挂载主机的 SFTP 授权不再生效；请挂载对应主机。不会自动挂载主机，也不会因此增加 SSH 命令权限。
- 不改变 FTP 的既有授权，不增加跨会话权限，不改变本地文件安全路径、审批或上传下载大小限制。
