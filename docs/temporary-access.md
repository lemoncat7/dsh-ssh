# 会话临时 SSH 授权

用户可以直接说“到 78 检查磁盘”或“到 192.168.28.127 排查服务”。Agent 使用 `ssh_request_temporary_access` 按已保存的主机名、完整 IP 或唯一 IPv4 尾号申请授权。目标存在歧义时必须进一步明确，不能自动选择。

DSH 原生授权确认框显示主机名、账号、地址和任务说明。只有用户同意后，Agent 才能通过 `ssh_temporary_exec` 在该主机执行本轮任务所需命令；这些命令可以修改远端文件。拒绝、取消或没有可用的确认界面都不会授予权限。

授权以 Agent 当前执行轮次为界：本轮结束、用户停止、Agent 报错、会话释放或插件重载时失效。下一轮需要重新确认。授权只保存在内存中，不改变手动挂载，不继承到子会话，主机配置改变后需要重新确认。延迟到达的确认不能恢复已结束任务的权限。

临时入口提供命令执行及 `cwd`，不自动授权文件传输工具、交互终端或端口转发。任务说明用于用户确认和审计，不是逐条命令的语义沙箱。用户授权后主动启动的远端后台进程不会因授权撤销而自动删除或停止。
