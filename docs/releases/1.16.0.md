# 1.16.0 — 主机管理与终端工作区分离

支持 DeepSeek Harness **0.2.2-rc.1**，Node.js **>=24.9.0**；依赖与授权边界不变。

## 界面与交互

- 第一页为「主机与项目」，支持卡片／列表、分组和主机／项目路径搜索。单击选择，双击或 Enter 打开终端；触屏也可使用明确的打开按钮。
- 不同主机共用终端标签栏，支持新建、切换、关闭、分屏及键盘导航。终端页不再常驻主机侧栏。
- AI 挂载使用独立按钮，选择主机和打开终端不会授予 AI 权限。授权摘要可展开查看与修改。
- 删除工具页重复的标题区：操作移到搜索栏、终端标签栏和文件路径附近；保留提示、错误、状态与连接控制。
- 文件面板跟随当前终端标签的主机，可独立浏览目录；支持仅浏览文件，不自动创建 shell。窄窗口可在终端与文件面板间切换。

## 迁移与边界

当前浏览器标签页内的旧终端记录自动合并到统一标签栏；配置、凭据和 AI 授权不变。离开工作台保留连接，明确关闭才断开；关闭失败保留标签。服务重启后无法恢复原 SSH 进程，不自动重跑命令。

## 验证

使用 DSH 0.2.2-rc.1 依赖构建，运行完整串行测试。真实 React/xterm 组件浏览器验证覆盖双击复用、跨主机切换与分屏、键盘导航、授权隔离、离开与刷新恢复、关闭失败重试、仅文件模式和 390px 窄屏；远端 API 使用隔离模拟，不向真实主机发送测试命令。
