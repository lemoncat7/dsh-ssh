# SSH 1.11.6

支持 **DeepSeek Harness 0.2.1-rc.2**，保留现有宿主兼容声明。

- 窄窗口的主机入口并入主机标题栏左侧，不再额外占一行；右侧操作依次为关闭所有终端、收起／展开 SFTP、删除主机。
- 按工作区实际宽度自动收起 SFTP，允许手动展开；普通缩放和切换主机不会反复覆盖手动选择。
- 当前会话权限下新增“新会话默认配置”，支持命令／终端模式和执行前确认。自动保存，仅用于尚未配置的会话和从项目新建的会话；不自动授予主机访问，不覆盖已有权限。初始执行前确认保持开启。
- 深色面板、卡片和控件使用插件自己的半透明材质，不依赖小黑主题；保留弹窗可读性和减少透明效果回退。

已完成自动测试和线上浏览器验证，覆盖窄窗口导航、按钮顺序、键盘焦点、默认权限保存与隔离。升级前备份配置，安装后重启对应 Profile。

安装：`dsh plugin --profile web add @lemoncat7/dsh-ssh@1.11.6`。
