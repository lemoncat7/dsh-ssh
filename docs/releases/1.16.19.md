# 1.16.19 — 终端分屏、主机搜索与工作台界面完善

本次正式发布包含自 **1.16.8** 以来已部署验证的更新。支持 DeepSeek Harness **0.2.2-rc.1**，需要 Node.js **>=24.9.0**。

## 终端与文件

- 每个终端标签拥有独立窗格，支持单屏、左右两屏、上下两屏与四格；缩减时选择保留的终端并确认关闭其余连接，同数量切换方向保留连接。
- 新建终端加号紧邻标签右侧。分屏与 SFTP 按钮保持靠右；底栏左侧依次为关闭所有终端、命令、断开，连接信息靠右且可点击查看详情。
- 关闭所有终端覆盖隐藏标签；关闭失败保留未成功关闭的连接。保留窗格选择弹窗减轻边框与阴影。
- 新建终端与端口转发共用可搜索主机选择器，可按名称、地址、用户名、分组和标签筛选。支持键盘操作、无匹配提示，列表不被卡片或弹窗裁切。搜索文字不会直接作为连接目标。
- 恢复默认跟随终端目录，保留各窗格手动关闭跟随的选择。主机支持显式配置终端到 SFTP 的路径前缀映射，适用于 NAS 虚拟目录根与终端路径不同的情况；映射仅作用于终端文件面板初始目录和自动跟随。
- 目录不存在统一返回 404；跟随失败保留上次成功列表并显示原因，首次加载失败后也可跟随新的有效目录恢复。

## 工作台与侧栏

- 主机、终端、文件传输及后续工具页面统一整块卡片背景，保留说明与操作入口；长设置页在卡片内滚动。
- 移除文件传输顶部重复的 FTP 管理入口，连接列表标题右侧依次为会话访问和 FTP 管理。
- 远端分组默认收起，展开按钮覆盖右侧快捷按钮以外的整行区域，支持鼠标与键盘。
- 主机与项目搜索下方说明主要用于给当前 AI 会话挂载主机与项目目录，访问范围由会话权限控制，同时保留手动终端用途说明。

已完成自动测试与桌面、窄屏浏览器验证，包括分屏保留选择、关闭失败恢复、目录映射、主机搜索及侧栏交互。生产运行仍支持 DSH 0.2.2-rc.1；插件版本为正式版。
