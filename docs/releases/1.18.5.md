# 1.18.5

- 优化已有终端运行时反复进入 SSH 面板的卡顿：复用最近终端的 xterm 界面和输出位置，重新进入仅补读新增输出，不再重建界面并从头回放历史。沿用原有远端终端，输入附着检查继续生效。
- 终端视图缓存在内存中，关闭的终端释放视图；闲置视图按最近使用顺序回收，目标总数 32，使用中的视图不回收。插件退出时清空，不写入历史输出缓存文件。
- 端口转发页不再提前初始化隐藏终端或批量读取隐藏主机的项目。主机信息不等待慢凭据列表；首次刷新与版本检查合并请求。
- 转发查询只读现有状态，不连接主机，不重启运行中的规则。连接认证失败正确显示错误，避免失败状态被当作停止。
- 进入端口转发页默认显示全部规则，主机栏为空；选择后过滤，清空或重新进入恢复全部。新建明确选择主机，编辑使用规则自身归属。
- 包含保存后操作按钮不可见与悬停方角修复：窄工作区操作换行，列表按圆角裁切。

验证：构建与 268 项测试通过；真实组件浏览器回归覆盖 8 个运行终端、每终端 2000 行历史、整个面板连续关闭／重开 5 次，确认同一 xterm DOM、非零输出游标与无新建 SSH 终端；同时覆盖慢凭据加载、隐藏页面无初始化、中英文、主机筛选、375–1024px、触屏及转发操作。浏览器 API 与输出流为隔离模拟，不连接真实 SSH。

桌面客户端更新 `@lemoncat7/dsh-ssh` 后重新加载插件客户端，继续沿用已保存规则。
