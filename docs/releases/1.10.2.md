# 1.10.2 · 主机挂载自动授权 SFTP

正式补丁版本，适配并验证 **DSH 0.1.7-rc.2**（宿主为 RC，插件为正式版）。Node.js **^22.19.0 或 >=24.0.0**。

- 当前会话挂载 SSH 主机后，自动获得对应 SFTP 的浏览、远端互传及会话目录上传／下载能力；卸载或删除主机后立即撤销。
- SFTP 传输确认沿用主机操作确认设置；不会额外增加 SSH 命令权限，也不会自动挂载主机。
- “FTP 会话访问”只管理 FTP/FTPS，其浏览、传输和确认策略不再影响 SFTP。
- 混合 SFTP 与 FTP/FTPS 传输会分别检查两端权限，任一端需要确认时都会申请确认。
- 服务端实时计算有效端点，清理旧客户端遗留的无效 SFTP 授权，并让接口返回最终生效状态。

验证：Node.js 24 下完成构建与 169 项自动化测试。授权行为和兼容边界详见 [主机挂载与 SFTP 授权](../host-sftp-access.md)。

本版本不修改持久化数据结构，不扩大跨会话权限，不改变本地文件安全路径及传输大小限制。如需回退，可安装上一正式版 `1.10.1`，原配置保持兼容。
