# 1.16.4 — 紧凑主机与固定目录

支持 DSH **0.2.2-rc.1**，Node.js **>=24.9.0**。

- 主机信息和悬停操作置于同一排，保留两行名称/地址；悬停提示复用地址行，不另占一排。
- 固定目录采用相同的悬停模式，仅在右侧保留挂载与更多菜单。名称和路径各一行，长文本省略；完整路径通过悬停提示查看。已挂载/默认目录不再额外增加一行。
- 目录的打开终端、默认目录、新会话及编辑操作收进顶层菜单；所有菜单项统一图标列。
- SSH 菜单在插件内部强制自己的背景、边框、字体、圆角、按钮、焦点和图标样式，抵御外部全局菜单样式覆盖，不依赖或修改任何主题插件。

验证包含长路径、已挂载目录、桌面/390px、悬停显示、菜单图标、目录编辑入口，以及注入全局!important规则后菜单计算样式保持一致。
