# 1.16.5 — 主机内部固定目录列表

支持 DSH **0.2.2-rc.1**，Node.js **>=24.9.0**。

- 固定目录改为主机卡片内部的紧凑子列表，统一缩进、顶部细分隔线及圆角悬停；取消目录逐行硬边框和挂载后的整块高亮，保留两行信息及同排悬停操作。
- 空列表使用单行「添加固定目录」入口。焦点框改为内描边，强制去除外扩阴影；目录区预留内边距并限制绘制边界，避免悬停/选中时遮住主机标题。
- 展开不再向上位移动画；主机卡片顶部与子列表边界衔接。顶层更多菜单与目录编辑弹窗继续可用。

验证覆盖空列表悬停/键盘选中、外部焦点样式覆盖、添加入口打开关闭、长路径、桌面/窄屏与既有交互回归。
