# 1.16.3 — 主机目录与操作收拢

支持 DSH **0.2.2-rc.1**，Node.js **>=24.9.0**。

- 当前会话权限改由工具栏按钮打开弹窗设置，保留保存状态与错误反馈。
- 主机默认隐藏操作，悬停/键盘焦点显示挂载、单双击说明和更多菜单；触屏保留可见入口。打开终端、编辑、删除及新增固定目录收进更多菜单。
- 单击主机展开或收起固定目录，双击打开终端并恢复双击前的展开状态；不会隐式改变 AI 授权。
- 当前会话已挂载主机所在分组默认展开，其余分组收起；当前页面手动选择优先于普通刷新。
- 主机更多菜单使用浏览器 popover 顶层，避免卡片裁切和主题层叠覆盖，并支持边缘避让、键盘导航和 Escape 关闭。

验证覆盖上述交互、窄屏触屏、权限弹窗保存、菜单顶层命中及跨主机终端回归。
