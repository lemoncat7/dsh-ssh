# 1.8.0

正式版。适配 DSH 0.1.5，已在 0.1.5-rc.1 镜像部署验证。需要 Node.js ^22.19.0 或 >=24.0.0。

- GitHub Gist 同步增加常用命令和分组代理配置；兼容旧备份缺少这些集合的情况，避免误删本地数据。
- 同步后自动更新代理库、主机与命令列表，保留正在编辑的草稿；页面隐藏时暂停检查，返回时检查更新。
- 主机分组支持默认代理：主机自己的代理或跳板配置优先，未配置时使用分组代理；已建立的连接不受修改影响。
- 统一 SSH 弹窗的标题、圆角、材质、留白和按钮规范；删除确认使用紧凑布局，适配手机和横屏。
- 凭据、代理、固定目录删除不再使用浏览器原生确认框；FTP 删除、文件删除、命令删除及终端关闭统一确认样式。异步删除失败可重试，处理中防重复操作。

安全说明：常用命令属于私有 Gist 中的配置元数据，并非加密凭据。请勿在命令中直接保存密码或 Token；密码、私钥仍独立加密。

验证：146 项自动测试通过；浏览器覆盖深浅色、375px/1024px、横屏、长名称、取消与失败重试，以及 Markdown 编辑与预览刷新状态保持。
