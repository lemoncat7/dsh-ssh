# 1.10.4 · 文件传输交互优化

插件正式版，适配并验证 **DSH 0.1.7-rc.2**。Node.js **^22.19.0 或 >=24.0.0**。

- 文件点击已经使用预览／下载弹窗，因此移除容易造成重复操作的“传送到下一栏”按钮；跨栏传输统一使用拖放。
- 拖放传输遇到目标同名冲突时，直接打开处理弹窗，无需先到任务列表点击“处理”；任务列表入口仍保留作键盘操作和异常恢复的兜底。
- 选择跳过、覆盖或自动改名并成功重新排队后，原失败任务会从界面和服务端历史中删除，不再与新任务同时显示。
- 文件传输页首次打开后保持挂载；在 SSH 工作台切换终端、命令、设置等标签再返回时，保留连接、目录、选中项、滚动位置、任务页和弹窗状态。

验证：Node.js 24 下完成构建与 173 项自动化测试。保留拖放以外的键盘可操作入口，不修改用户配置和传输数据格式。可回退至 `1.10.3`。
