# 1.5.3

插件正式版，适配 DSH 0.1.5 的主面板与原生右侧标签 API，保留旧版主面板回退。已在 DSH 0.1.5-rc.1 镜像验证；DSH 本身仍是 RC 版本。

- SSH 工作区使用新版主面板导航；右侧栏支持与知识库等插件标签共存、分栏及独立关闭。
- 隐藏侧栏内容停止轮询，切换会话或卸载时取消待执行的打开请求。
- 终端固定深色滚动区及滚动条样式，避免浅色主题干扰；不禁用终端滚动。
- 右侧栏统一为知识库同款透明标题、半透明控件及文件列表；移除搜索和目录路径输入框被主题强加的绿色焦点圈。
- 不修改 SSH/FTP 权限、认证和文件操作逻辑，无新增数据迁移。

验证：123 项自动化测试通过；新版正式部署浏览器可打开工作区，无页面异常。未以发布检查代替真实远端连接验收。
