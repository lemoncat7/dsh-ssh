# v1.4.3

正式版，适配 DeepSeek Harness **0.1.2-rc.1**，需要 Node.js **22.19+ 或 24+**。

## 新功能

- SSH 右侧目录和本地会话目录支持输入文件路径直接预览，保留相对路径、空格文件名和无扩展名文件支持；打开文件不改变会话工作目录。
- 新增 `file_download_to_local` Agent 工具：默认写入当前 DSH 会话目录，可指定目录内的相对目标路径。受文件端点权限、执行前确认、并发、大小和超时限制；流式暂存并独占提交，不覆盖已有文件。
- 工具中的“本地”指 DSH 服务所在机器，而不是浏览器的下载目录。当前支持普通文件，不支持目录。

## 性能与可靠性

- FTP LIST/MLSD 不再对每个软链接或未知条目串行发送目录探测命令，改为显式进入目录或单项 stat 时确认。
- 名称排序复用比较器；本机一万条排序基准约从 809ms 降至 30ms（不含网络，不保证所有设备相同）。
- 保留大目录虚拟列表，递归传输仍不跟随软链接，FTP 控制连接保持串行使用。
- 已取消的 FTP 操作在发送命令前退出，避免取消后的未处理异常。

## 验证

- 89 项自动化测试。
- 375px / 1024px 浏览器路径输入与 FTP 一万条列表交互测试。
- 发布与本地部署使用同一个本地构建的安装包。

FTP 协议仍需接收完整目录列表，服务器和网络耗时不属于本次优化消除的范围。
