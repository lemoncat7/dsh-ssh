# 1.11.1 · 终端中断与挂起修复

适配 DSH **0.2.0-rc.2**；需要 Node.js **^22.19.0 或 >=24.0.0**。

- 修复 #3、#4：不再通过 SSH channel.signal 向会话 shell 投递信号；SIGTSTP 改用 Ctrl-Z，SIGINT/QUIT 使用 Ctrl-C/Ctrl-\\。
- `ssh_terminal_signal` 返回 `inputWritten: true` 和 `mechanism: pty-control-byte`，不再伪造 `delivered: true, targetPgid: 0`。
- **调用方注意**：工具只支持 SIGINT、SIGQUIT、SIGTSTP。SIGTERM/KILL/HUP 不再宣称支持；关闭终端使用 ssh_terminal_close。宿主要求真实前台 PGID 的接口在无法验证时明确报错。
- 取消发送使用 Ctrl-C；终端退出、写入失败或无效信号不返回成功。
- 验证：182 项测试（umask 022）；隔离 Linux PTY 实测 Ctrl-C 中断、Ctrl-Z 挂起前台 sleep。没有向用户远程主机发送测试信号。

原始模式或自定义 stty 可能改变控制字符处理；写入成功不等于已经验证进程收到 POSIX 信号。升级不改变主机、密钥、授权或传输配置。
