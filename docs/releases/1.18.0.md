# 1.18.0

- 分组标题新增「整组挂载」和「整组卸载」，显示已挂载数／完整组主机数；部分挂载时两项均可使用，空组禁用操作。「未分组」沿用相同规则。
- 搜索只影响主机显示，整组操作始终包含当前完整分组，并显示范围提示。操作按点击时的成员执行，之后新增或移入的主机不会自动获得挂载。
- 当前会话单独配置时一次保存整组改动，失败恢复原状态；继承项目时先进入「编辑项目挂载」，整组操作修改草稿，确认后影响继承该项目的会话，取消则丢弃草稿。
- 已挂载主机的固定目录与默认目录保留；新增主机不自动挂载固定目录。卸载同步清理对应主机的目录引用，保留其他组及独立的文件访问授权。
- 增加中英文文案、窄屏分组操作布局、批量目录清理测试和隔离浏览器回归脚本。实际验证记录见本地部署报告；本说明文件不代表已经发布到 npm 或 GitHub。
