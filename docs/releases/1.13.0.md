# SSH 1.13.0

设置增加「配置导入与导出」。无需连接 GitHub，即可下载由密码保护的 JSON 备份，或解密文件、预览数量后导入。

- 整个备份文件使用 scrypt 派生密钥和 AES-256-GCM 加密，包含地址及凭据；密码至少 8 位，文件最大 1 MB。备份密码不会改变同步密码。
- 备份范围：SSH、FTP/FTPS、项目目录、密钥库、代理库、分组代理和常用命令。会话授权、端口转发、本机运行设置及 GitHub 授权不包含在备份中。
- 导入为独立副本，保留现有配置；重新建立凭据、代理、跳板与项目引用，分组使用独立名称。重复导入会产生另一份副本。
- 导入先验证密码、文件和引用，再写入凭据与配置；配置提交失败时清理新增凭据。导入与云同步排队执行，已开启的自动同步会处理新增条目。
- 自动同步卡片恢复完整留白：桌面左右 24px、上下 20px，窄屏 18px；说明可换行，开关不挤压文字。

适配 DSH 0.2.1-rc.2，Node.js ^22.19.0 或 >=24.0.0。现有配置无需迁移，生产依赖未增加。

验证：199 项测试通过，包含文件加密往返、错误密码、文件篡改、导入引用、冷启动读取、写入失败清理、云同步排队及 HTTP 管理请求保护。真实组件在 375/1024/1600px、深浅色共六组隔离浏览器流程通过，覆盖下载、密码校验、解密预览、确认导入与既有同步配置流程。

浏览器测试使用隔离 API fixture，不修改生产 SSH 主机或触发真实 GitHub 同步。
