# 1.15.0

支持 DSH **0.2.2-rc.1**，Node.js **>=24.9.0**。

- 修复 #7：离开 SSH 工作台不再删除远端终端；返回及刷新恢复同一浏览器标签页、同一会话内的主机、终端标签与分屏，重新接入服务端输出。
- 明确关闭/断开才删除连接，失败保留引用并显示错误；处理连接未建立就离开或关闭的竞争，避免遗失后台连接。
- 恢复连接时更新输入代次和序号，拒绝旧页面迟到输入，防止按键被重复输入去重逻辑吞掉。此逻辑仅影响手动工作台终端，AI 终端授权保持原行为。
- 有输出或活动订阅时不会被 30 分钟空闲计时回收；离开且无活动满 30 分钟仍会回收。持续无输出的后台任务请用 tmux/screen。
- 修复已建立 SSE 在终端失效后无限重连的问题；短暂重连未恢复则以游标轮询核实终端状态。失效连接提示手动重连，不自动重新执行命令。
- React StrictMode 恢复时避免重复初始化终端造成的异步视口报错。

## 验证与边界

覆盖生命周期、真实 HTTP 接管协议、输入去重与旧代次拒绝、连接中关闭、回收时钟、存储恢复及会话隔离。浏览器隔离验收覆盖 StrictMode、离开/返回、刷新、分屏、恢复输入、关闭失败重试与失效不重跑；模拟远端接口，不向真实主机发送测试命令。

升级需要重启 Profile，现存 SSH 通道会随重启断开；本次能力不提供跨服务重启的远端进程恢复。sessionStorage 不含凭据或终端输出，服务端输出缓存有界，过早输出可能截断。已有 SSH 主机、凭据和授权配置无需迁移。
