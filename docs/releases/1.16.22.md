# 1.16.22

支持 DSH **0.2.2-rc.1 / 0.2.2-rc.2**，Node.js >=24.9.0。

- 修复插件热更新、卸载或重新挂载时可能触发 `removeChild` 异常、导致整个左侧栏消失的问题。侧栏入口改用 React Portal，原生插槽节点保持原位，只移动插件自己的容器。
- 保留工作区上方的入口位置、伙伴/远端顺序，以及原生工作区内容；覆盖新旧实例重叠、StrictMode、工作区替换、侧栏收起与展开、目标区域暂缺时的回退。
- 浏览器回归：`npm run test:sidebar-browser`（需安装 Playwright 和 Chromium，或用 `DSH_PLAYWRIGHT_MODULE` 指向已有安装）。测试自动关闭浏览器、HTTP 服务并清除临时构建。
