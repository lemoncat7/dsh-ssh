# SSH 1.12.0

同步从设置中独立为一级页面。智能同步、自动同步、冲突策略和备份数量直接显示在页面上；账号授权、同步空间和加密密码通过弹窗中的三步向导配置。

- 提供清晰的 Token 与浏览器授权入口，不再把首次授权必填项藏进高级设置。
- 使用基于 React Bits Stepper 适配的引导，支持返回修改、字段校验、错误重试、授权等待、键盘操作与减少动态效果。
- 已连接账号通过“管理配置”维护；切换工作台页面保留未保存的同步偏好。
- 账号验证独立于旧 Gist 的读取和解密，避免旧同步空间故障阻断重新授权。
- 自动更新同步状态；代理配置归入同步页，保存时保留当前实例的其他运行设置。
- 同步方式列表目前仅 GitHub Gist 可用，WebDAV、S3 明确标注尚未接入。
- 明确说明凭据加密范围：密码、私钥等凭据加密上传；主机地址等配置在非公开 Gist 中保持明文。

验证：TypeScript/客户端构建，195 项回归测试（新增授权与存储故障解耦用例），375/1024/1600px 明暗主题共六组浏览器流程，包括空值阻止提交、授权失败重试、返回保留输入、保存失败重试、OAuth、同步策略和代理设置。

界面测试使用隔离 API fixture，不连接或修改生产 SSH 主机，不触发真实 GitHub 同步。React Bits 授权声明见 `docs/third-party/react-bits.md`。
