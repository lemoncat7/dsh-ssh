# 1.11.3-style.1（本地体验版）

适配 DeepSeek Harness 0.2.0-rc.2，沿用知识库 2.13.12 的交互风格。

- 统一按钮、表单、菜单和右侧活动页签的圆角、层次与短过渡。
- 管理弹窗采用居中圆角外框与内嵌内容区，窄屏保留边距，内容按需滚动；文件预览与终端布局不变。
- 保留键盘焦点反馈，尊重减少动态效果偏好；不增加加载依赖或持续动画。
- 不改变主机挂载、访问授权、文件传输及连接协议。

浏览器回归脚本：`scripts/verify-workbench.mjs`。宿主 UI 测试依赖可通过 `DSH_UI_TEST_NODE_PATH` 指定独立目录（冒号分隔），不会加入插件运行依赖。
