# 1.11.0 · 主机分组管理与临时授权

- 支持主机拖动到其他分组，分组默认折叠；编辑主机时也可选择分组。
- 顶部新增菜单提供新增主机、新增分组；分组可独立保存，支持名称和默认代理。
- 主机右侧菜单提供编辑主机、添加固定目录，移除工作台重复编辑入口。
- 分组编辑支持一键重置组内主机代理，以及删除分组；删除后主机与固定目录保留，主机移到未分组。分组代理移除后，原继承代理的主机将直连，需重连生效。
- 支持按主机名、完整 IP 或唯一 IPv4 尾号申请本轮临时 SSH 命令授权。用户确认后生效，本轮结束、停止或报错自动撤销，不改变永久挂载、不继承给其他会话。详见 [临时授权说明](../temporary-access.md)。
- 菜单支持键盘操作，分组操作使用紧凑文字按钮并提供二次确认。

适配 DSH 0.2.0-rc.2，需要 Node.js ^22.19.0 或 >=24.0.0。已完成构建、分组与临时授权测试、375px/1024px 页面检查及本地容器部署验证。
