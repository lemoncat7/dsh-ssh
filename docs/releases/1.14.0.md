# 1.14.0

适配 DeepSeek Harness **0.2.1-rc.2**，Node.js **^22.19.0 或 >=24.0.0**。

- 修复 #5：设置中可调默认 SSH 连接超时，主机编辑器可独立覆盖；新建主机测试也生效。区分握手和已核验指纹后的认证超时。
- 可选终端连接复用，默认关闭。并发新建共享一次认证，独立 shell/目录/输出与关闭；会话隔离、空闲回收、配置/凭据变更失效、失败淘汰和取消保护。
- 原 20 个 SSH/文件操作收敛为 `ssh` 一个宿主工具，按需 `list / describe / call`，执行仍使用原参数校验、会话权限与审批政策。
- 设置保存串行合并，失败保留反馈，沿用插件现有布局与中英文文案。

迁移注意：自定义工具白名单需将原 SSH/文件工具名改为 `ssh`。旧会话中的操作名称仍可作为 `tool` 参数，但不再独立注册。挂载与授权数据无需迁移。连接复用不加快第一次认证，且共享连接断开会影响其上的终端。
