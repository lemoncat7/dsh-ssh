# 1.19.1

修复固定目录右侧三点菜单弹出后，鼠标离开目录行且焦点移走时，菜单仍显示却无法选择的问题。

- 菜单打开期间，嵌套的操作区域保持可见和可点击，不再依赖目录行的悬停或焦点状态。
- 原生弹出菜单明确接收指针事件，避免点击穿透到下方的挂载或卸载按钮。
- 浏览器回归检查加载与插件相同的完整样式，覆盖焦点移走后的菜单点击、取消编辑、重新打开、Esc 与点击外部关闭，并复查挂载、默认目录及继承模式切换。

问题已在两个 Chromium 版本中复现并验证修复；部署后也在实际 DSH 页面验证了焦点移走后的编辑和取消操作。现有主机、目录及权限配置无需迁移。

安装或升级后重启对应的 DSH Profile，并刷新浏览器页面。
