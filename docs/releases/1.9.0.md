# 1.9.0

正式版。适配 DSH 0.1.5，已在 0.1.5-rc.1 镜像部署验证。需要 Node.js ^22.19.0 或 >=24.0.0。

- 修复 FTP 文件识别、目录进入、大小和修改时间解析及排序；文件传输默认单栏，保留多栏选择。
- 本机上传、下载与远端传输统一显示在传输任务列表，支持任务时间与终态清理。
- 支持文件保存接口的浏览器按实际写入字节显示下载进度，保存关闭成功后才显示完成。其他浏览器或 Desktop 环境交由原生下载，不伪造进度或保存成功状态。
- 文件传输页增加本机文件上传，支持 FTP、FTPS、SFTP，多选文件依次上传；发送完成后等待远端保存确认。
- 会话访问增加 Agent 本地上传、下载独立授权，默认关闭，同时要求端点授权和传输权限；新增 file_upload_from_local 工具。
- Agent 本地指 DSH 运行机器的当前会话目录，不是浏览器电脑。上传仅支持目录内普通文件；下载默认保存在该目录；单文件最大 512 MiB，限时五分钟。
- 上传使用临时文件、大小校验及最终改名；同名文件按冲突处理，不主动覆盖。FTP 协议无法保证其他客户端并发改名时的排他提交。

升级提醒：原先允许远端传输的会话不会自动获得本地上传／下载权限，请在“文件传输 → 会话访问”明确开启。

验证：163 项自动测试通过；传输页面覆盖 375/697/1024px、深浅色及一万条目录记录；浏览器测试覆盖实际流式写入、保存确认、取消、失败及上传进度。Desktop 原生文件保存接口未实机验证，不支持时明确显示无法确认进度。
