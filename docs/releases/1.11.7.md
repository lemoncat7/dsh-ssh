# SSH 1.11.7

支持 **DeepSeek Harness 0.2.1-rc.2**，兼容声明与依赖保持不变。

- 修复主题为 SSH 弹窗外层添加背景、边框及不同圆角，导致内部圆角后露出近似直角底板的问题。
- 普通弹窗保持外层透明，由内部面板绘制背景；文件预览和新建会话弹窗保留自身材质，并沿统一圆角裁剪内容。
- 手机宽度下同步内外层圆角，不修改其他插件或宿主弹窗的主题样式。

验证：浏览器样式对照覆盖 Rift、小黑、Realm 三套主题的桌面与手机宽度；修复样式已在线上加载验证。

无需迁移配置。安装后重启对应 Profile，并刷新浏览器。

安装：`dsh plugin --profile web add @lemoncat7/dsh-ssh@1.11.7`。
