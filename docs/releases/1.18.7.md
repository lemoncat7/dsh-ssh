# 1.18.7

- SSH 弹窗统一使用现有微透玻璃材质，移除内层灰框与厚底色，适配明暗、手机和减少透明度偏好。
- 聊天输入框新增 `@` 搜索已保存的主机名和 IP，候选显示用户名、地址及端口，同名主机可区分；发送时按 profileId 核对最新地址，不连接主机或读取凭据。
- 临时访问支持下一轮回复 `1`、`同意`、`可以` 等简短确认，兼容原确认语；继续核对主机配置、任务、伙伴、任务范围和十分钟期限，跨会话、改换范围、过期或非用户消息不生效。

- SSH 弹窗不再压暗或整体模糊背景；保留弹窗自身玻璃、焦点约束及关闭行为，不影响其他插件遮罩。
- 端口转发规则定义加入 Gist 同步与加密备份，支持新增、编辑、删除、旧快照迁移和导入时主机引用重映射。运行状态与自动启动保留在本机，新同步规则默认停止；目标改变时停止旧连接，避免显示与实际连接不一致。两端均需支持 1.18.7；旧桌面端更新并上传后，服务器才能获得它原先的规则。
