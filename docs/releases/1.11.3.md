# 1.11.3 · 统一工作台交互与聊天临时授权

适配 DeepSeek Harness **0.2.0-rc.2**；需要 Node.js **^22.19.0 或 >=24.0.0**。不改变现有宿主版本约束。

## 工作台样式

- 与知识库工作区统一圆角按钮、输入框、搜索、下拉框及短动效；覆盖终端、主机、代理、文件传输和配置弹窗。
- 弹窗按视口居中、自适应宽高，统一头部、关闭入口和底部操作区；保留浅深主题、窄屏和减少动画支持。
- 不改变主机挂载、终端会话、凭据和文件传输行为。

## 临时 SSH 授权

- 核验当前真实用户消息中的明确主机操作授意，不再强制请求独立审批弹窗。不会将 Agent 自报同意、旧聊天、工具输出或后台通知当成用户授权。
- 语义不明确时返回完整授权范围，在聊天中等待用户确认；短确认绑定原申请及主机配置，10 分钟内有效，不能改换目标或任务。
- 普通授权仅当前执行轮次有效；结束、停止、错误、释放或重启后失效，不改变永久挂载。
- 搭配伙伴插件 **2.8.4**，可为明确指定的看板任务和执行伙伴授权：任务暂不运行，授权通过后再提交；仅一次执行、最长 60 分钟，不自动共享给其他伙伴、验收者或重试。
- 临时授权只提供远端命令及工作目录，不自动开放文件传输、交互终端或端口转发。任务说明不是逐条命令沙箱；远端自行启动的后台程序不保证随本地撤销而退出。

## 验证与升级

- 192 项测试通过；跨插件模拟验证用户授意、指定任务绑定、执行边界及撤销。
- 工作台浏览器回归覆盖 375 / 1024 / 1600 像素、浅深主题；功能代码与已部署的 `1.11.3-style.3` 试用版一致。
- 无数据迁移。升级插件并重启对应 Profile，刷新页面；临时授权不会跨重启恢复，旧受阻任务不会因升级自动重跑。
