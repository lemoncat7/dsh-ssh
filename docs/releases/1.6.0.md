# 1.6.0

正式版。适配 DSH 0.1.5 主面板与右侧标签 API，已在 0.1.5-rc.1 镜像部署验证。Node.js 要求 ^22.19.0 或 >=24.0.0。

- 文件预览整合刷新按钮与手动／自动模式；自动模式按需检查变化，隐藏时暂停，刷新保留滚动位置。
- HTML 支持隔离的静态预览及源码查看；不执行脚本或加载外部资源，暂不支持编辑。
- 支持本地会话目录及 SFTP Markdown 正文直接编辑，无需编辑模式按钮；手动保存或 Ctrl/Cmd+S，自动刷新时只读。
- 草稿在当前浏览器标签页内保留，保存失败及版本冲突不丢弃草稿；支持下载草稿、确认后放弃。
- 保存校验内容版本、目录权限及文件类型，使用临时文件与原子替换；SFTP 服务器不支持原子替换时安全拒绝，不删除原文件。
- 编辑仅支持不超过 256 KiB 的完整 UTF-8 .md；含不支持结构的文档保持只读。外部程序不参与插件写锁，最终校验到替换间仍有极短并发窗口。

验证：127 项自动测试通过；浏览器回归覆盖刷新、HTML 隔离、Markdown 保存、冲突与草稿恢复，以及移动端路径输入。
