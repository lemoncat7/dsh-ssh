# 1.11.3-style.3 · 聊天临时授权（本地预览）

- 当前真实用户消息中的明确主机操作指令可建立临时授权，不再请求 DSH 审批弹窗。
- 不明确时展示完整范围后等待聊天确认，确认绑定原申请、10 分钟有效，不接受 Agent 自报授权。
- 与伙伴插件 2.8.4-style.4 联动：支持指定看板任务和执行者的一次执行授权，最长 60 分钟，不共享给其他任务、重试或验收者。
- 保留会话/轮次边界、主机指纹检查及取消撤销；不改变永久挂载、文件传输或端口转发权限。
- 适配 DSH 0.2.0-rc.2，无数据迁移。详细边界见 `docs/temporary-access.md`。
