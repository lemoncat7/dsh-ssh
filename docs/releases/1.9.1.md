# 1.9.1 · 主机指纹变更确认

正式版。已验证宿主 DSH **0.1.5-rc.1**；需要 Node.js **^22.19.0 或 >=24.0.0**。保留旧宿主兼容回退，未重新完成旧宿主端到端验证。

- 重装系统导致主机密钥变化时，编辑主机并测试连接可查看新旧指纹，明确核实后重试，不再只能看到 Host denied。
- 跳板链准确报告发生变化的主机，单独确认跳板机，不覆盖目标主机指纹。
- 确认时先验证连接再保存，失败不覆盖原信任记录；并发修改配置时拒绝过期确认。
- 当前主机测试成功后仍需保存；跳板机确认成功会单独保存其指纹。不会自动信任新密钥，不解除被引用跳板机的删除保护。
- 指纹完整换行显示，沿用现有警告和按钮样式，支持小屏。

验证：164 项自动测试通过，另有 375/844/1440px 页面确认流程与跳板机身份检查。请通过服务器可信控制台核实新密钥后再确认。
