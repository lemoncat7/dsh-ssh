# 1.19.3

修复切换会话后返回 SSH 活动时，终端界面反复重建和全量历史重放的问题。

- 复用已有终端视图缓存，按会话、原生侧栏页签及终端标识隔离，保留 xterm、输出游标、滚动位置和输入序号。返回时只读取新增输出，不创建新 SSH 连接或远端 shell。
- 隐藏时停止输出订阅；初始隐藏面板不初始化终端。首次初始化让出会话提交，快速切走或 StrictMode 的临时挂载不会遗留终端实例。
- 视图缓存在内存中按最近使用顺序回收，目标上限 16，使用中的不回收；终端移除及插件退出清理对应资源。后台不把输出缓存写入文件。
- 上游历史被截断时清空过期本地内容，后续状态/输入仍走原有服务端权限校验。不同页签不会争抢同一份终端 DOM。

验证：321 项测试通过；浏览器使用真实 React/xterm 和隔离 HTTP/SSE，覆盖会话往返、隐藏后增量恢复、历史滚动、输入序号、截断、终端移除、初始隐藏及插件清理。4 倍 CPU 降速下，两条约 22 万字符历史终端往返 4 轮，实例创建从 9 次降为 2 次，解析量从 2,007,981 降为 446,218 字符。宿主图标及目录组件为隔离替身，未连接用户主机；这不是用户桌面上的实测秒数。

桌面本机需要更新插件并刷新客户端页面才能应用此修复。更新需重载 Profile 时，按正常插件升级流程进行；不要把服务器更新当作桌面本机已经更新。
