# 1.5.0

正式版，适配 DeepSeek Harness **0.1.2-rc.1**；需要 Node.js 22.19+ 或 24+。

- 同一主机支持挂载多个目录，独立指定默认工作目录。
- 终端支持最多 8 个标签、4 个分屏；可见标签仅切换焦点，不交换窗格位置。
- 紧凑终端工具栏，支持收起右侧 SFTP。
- 新增常用命令页面，选择命令后预览并确认执行。
- 统一工作台材质与布局，适配手机、平板和桌面。
- 修复 GitHub 授权处理：401 先复核，不直接删除 Token；旧请求不覆盖新授权。确认授权异常后暂停自动同步，保留失败时间，支持重启后手动重试恢复。

注意：旧版本已删除的 GitHub Token 需要重新授权一次。常用命令暂不参与 Gist 同步。

验证：108 项测试通过，6 组响应式明暗主题浏览器检查通过。
