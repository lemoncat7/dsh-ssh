# 1.18.2

- 分组标题支持整组挂载／卸载，部分挂载时两项均可用；空组禁用，「未分组」沿用相同规则。
- 操作在鼠标悬停或键盘聚焦时显示，触屏保留直接入口。完整分组的已挂载数量固定于右侧，两个挂载按钮位于数量左侧；按钮使用统一字号并收紧间距。
- 搜索只过滤显示，整组操作包含隐藏主机并显示范围说明。分组不建立持续自动授权，之后新增或移入的主机需再次挂载。
- 独立会话一次保存，失败恢复原状态；项目挂载先编辑草稿，确认后对继承项目的会话生效，取消则丢弃改动。
- 保留已挂载主机的固定目录与默认目录；新增主机不自动挂载固定目录。卸载清理目标主机及其目录引用，保留其他组及独立文件访问授权。
- 验证覆盖整组状态、目录清理、失败回退、草稿取消／确认、悬停和键盘操作，以及 375px、1024px 的中英文布局；隔离浏览器测试不连接真实 SSH 主机。
