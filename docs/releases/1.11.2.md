# 1.11.2 · 会话状态与文件预览优化

适配 DSH **0.2.0-rc.2**；需要 Node.js **^22.19.0 或 >=24.0.0**。

- 打开 SSH 工作台时保留左栏当前会话高亮。
- 优先选择当前会话挂载的主机，自动展开对应分组；普通刷新尊重手动折叠状态。
- 右栏按会话保留标签页、主机、浏览目录、文件预览和目录滚动位置，切换会话或关闭再打开不再初始化。状态仅在当前页面生命周期内保留，不跨浏览器刷新。
- 扩展 SQL、TXT、脚本、配置等文本预览；未知后缀也尝试识别 UTF-8 或带 BOM 的 UTF-16。过大、二进制或无法读取的文件显示下载入口。
- 文本预览上限 1 MiB，图片/PDF 上限 16 MiB。恢复预览重新鉴权，不缓存内容或授权，不改变主机、密钥和传输配置。

验证：187 项测试通过；375px 和 1200px 隔离浏览器检查通过；线上修复部署后的服务健康、编译文件一致性和文本预览运行检查通过。

详见 [会话工作台与文件浏览状态](../session-browser-state.md)。
