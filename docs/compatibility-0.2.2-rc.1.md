# DSH 0.2.2-rc.1 兼容性

插件版本：1.14.2。目标宿主：官方 @deepseek-ai/dsh@0.2.2-rc.1；Node.js >=24.9.0。

按新提示词文本组装类型适配；独立文件工具使用条件注册，执行权限继续由原操作校验。插件未维护独立PTC SSH helper，不复制旧协议2实现。

此版本面向0.2.2-rc.1；回退宿主时请同时恢复升级前插件包和数据快照，不让旧宿主写入新宿主迁移后的数据。验证结果见部署仓库 COMPATIBILITY-022-RC1-20261105.md。

## 专项复核

旧版不可直接宣称兼容。0.2.2 的 `system-prompt/assemble` 使用不含工具列表的 `PromptPresentation`；独立文件工具的旧过滤逻辑会访问不存在的 `tools`。候选版已用条件注册控制可见性，并保留现代提示词中的文件访问与交付说明。正常统一 `ssh` 入口仍在插件内部管理子操作，其他插件不经它转调。

专项复核修复了迁移中独立文件工具模式可能漏掉访问说明的问题；增加不含 `tools` 的提示词对象回归断言，确认没有向提示词补造工具列表。完整构建及 209 项测试再次通过（`ssh-verified-tests.log`）。页面打开、窄屏检查通过；尚未进行生产远程主机的端到端连接验收。
