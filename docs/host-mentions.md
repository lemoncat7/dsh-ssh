# 聊天中的 SSH 主机引用

在聊天输入框输入 `@` 后，可按已保存的主机名、IP 或分组搜索。候选同时显示名称和 `用户名@地址:端口`，同名主机可通过地址区分；选择后插入主机引用，点击引用可打开对应主机面板。原有文件、会话和笔记候选继续共存，键盘导航由 DSH 原生输入框负责。

发送时按保存的 profileId 重新读取当前地址；主机删除或不可用时会明确报错，不回退到另一个同名主机。搜索只读取保存的基本信息，不读取凭据、不连接主机、不修改挂载。输入停止 150ms 后才查询，过时查询会取消，最多返回 20 项，没有后台轮询或落盘缓存。

引用用于定位主机，本身不授予 SSH 权限。临时访问仍先展示主机和任务范围；下一轮回复 `1`、`同意` 或 `可以` 即可确认，同一次申请必须保持主机配置、任务、指定伙伴和看板任务不变，最长十分钟有效。
